# Project sources

This was an individual project completed for Design and Manufacturing of Electronics at Hochschule Rhein-Waal.

The course provided the circuit schematic, KiCad template, board outline, fixed connector positions and four-layer stack-up requirements. I completed the PCB placement and routing, physical assembly, hardware testing, debugging and repair.

## Scoppy software and reference design

- [Scoppy GitHub project](https://github.com/fhdm-dev/scoppy)
- [Scoppy project website](https://oscilloscope.fhdm.xyz/)

The Scoppy firmware, Android application and reference circuitry are maintained by their respective authors and are not included in this repository.

## Hardware references

I used the Raspberry Pi RP2040 datasheet, *Hardware Design with RP2040*, component datasheets and the course KiCad material as design references. The included component libraries retain their original part information and reference links.

## Photographs

All photographs show my physical prototype. The main project page uses the presentation photographs, while the original photographs are included in the [photo index](images/README.md) as additional build documentation.
